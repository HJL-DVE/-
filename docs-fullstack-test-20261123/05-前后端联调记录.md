## 四、⚠️ 联调受限项（环境限制，非代码缺陷）

### 券抵扣链路（order-service → marketing-service Feign）

| 场景 | 期望 | 实际 |
| --- | --- | --- |
| marketing 与 order 同在宿主机 | 券抵扣生效 | ✅（历史回归 34 号脚本 10/10 通过） |
| marketing 在容器、order 在宿主 | 券抵扣生效 | ❌ 抵扣 0 |

**根因**：宿主机无法路由 Docker 内网 IP（实测 TCP 超时），Feign 调 marketing 失败 → order-service 按设计降级为「券抵扣 0，不阻断下单」（这本身是正确的容错设计）。

**判定**：非代码缺陷，是混合部署限制。已单独验证营销服务自身接口正常（`/usable` 返回券、`/internal/coupons/quote` 正常返回抵扣额）。

### 报表接口

report-service 停机时 Gateway 返回 `10302`；前端正确降级不白屏 ✅。
