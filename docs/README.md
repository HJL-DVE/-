## 阅读顺序建议

**想了解"做什么"** → 01 需求分析与功能清单

**想知道"怎么搭"** → 02 系统架构设计

**想看懂"数据怎么存"** → 03 数据库设计

**想理解"钱怎么算"（最核心）** → 04 核心业务规则与资金安全设计

**想调接口** → 05 接口规范与安全设计

**想参与开发** → 06 项目目录规划 + 07 开发计划与里程碑

**想部署** → 08 环境预研与部署规划

---

## 文档维护规则

1. 任何业务规则的变更，先改文档，再改代码。
2. 数据库 DDL 变更必须在 `docs/03` 与 Flyway 脚本中同步。
3. 统计口径定义只允许在 `docs/03` §7 中修改，代码引用该定义。
4. 每阶段结束更新本索引的"状态"与"最后更新"。
