### 1.3 前端基础设施

| 能力 | 实现 |
| --- | --- |
| 统一 Axios | `src/api/request.ts`：baseURL 取 `VITE_API_BASE_URL`；请求拦截注入 Bearer + `X-Trace-Id`；超时 10s；响应拦截 `code===0 → data`、401 跳登录、4011 清 token、403 提示、其余 ElMessage；网络异常/超时统一提示 |
| 文件上传 | `http.upload()` multipart 封装（契约无上传接口，属预留能力） |
| 登录态 | Pinia `stores/user`，token 持久化 + 路由守卫（仅 `/login` 免登录，深链刷新正常） |
| 动态菜单 | `GET /api/admin/auth/menus` 渲染侧边栏；页面组件由前端 `viewRegistry` 本地注册 |
| 多门店 | Pinia `stores/app` 存 `currentStoreId`（localStorage 持久化），数据源固定 `store/stores/accessible` |

### 2.2 与契约第六节的差异（如实说明）

| 项 | 契约 | 实现 | 原因 |
| --- | --- | --- | --- |
| 页面数 | 18 | 19（+购物车） | 购物车是下单必需环节，单列一页 |
| 积分 / 优惠券 | 「入口」 | 独立页面 + 敬请期待 | 契约只要求入口，不要求功能；无后端接口 |
| 糖度/温度/加料 | 规格选择 | 合并写入订单 `remark` | `OrderItemRequest` 无 `remark` 字段，规格文案写订单级备注，未擅自改契约 |

### 2.3 小程序基础设施

| 能力 | 实现 |
| --- | --- |
| 统一请求 | `src/utils/request.ts`：baseURL 固定 `http://127.0.0.1:9000`（全项目**唯一**出现网关地址处）；注入 `Bearer`；`code!==0` toast；401/4011 清 token 跳登录 |
| 金额 | `utils/money.ts` 整数分运算（`fen2yuan/yuan2fen/sumFen`），购物车用整数累加 |
| 状态管理 | Pinia：`auth`（token/会员）、`store`（当前门店）、`cart`（购物车 + 规格） |
| 支付铁律 | **无任何本地加余额代码**；充值结果页只轮询 `wallet/recharges/{no}` 与 `wallet/account` |
| 构建 | `npm run build:mp-weixin` → 94 个产物、19 个 wxml，`project.config.json` `urlCheck=false` 便于本地联调 |
