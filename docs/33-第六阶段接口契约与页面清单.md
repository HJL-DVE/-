## 一、全局约定

| 项 | 约定 |
| --- | --- |
| 网关地址 | `http://127.0.0.1:9000`（**所有业务请求必须经网关**） |
| 响应包装 | `{ code, message, data, traceId, timestamp }` |
| 成功判定 | `code === 0` |
| 分页入参 | `pageNo`（从 1 开始）、`pageSize` |
| 分页出参 | `{ records, total, pageNo, pageSize, totalPages }` |
| 金额单位 | **分**（整数）。前端展示除以 100，禁止浮点运算金额 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 认证 | `Authorization: Bearer <token>` |

### 错误码（`ResultCode`，前端需按码处理）

| code | 含义 | 前端行为 |
| --- | --- | --- |
| 0 | 成功 | — |
| 401 | 未登录 / Token 缺失 | 跳登录 |
| 4011 | Token 过期 | 清理并跳登录 |
| 403 | 无权限 | 提示无权限 |
| 404 | 资源不存在 | 提示 |
| 500 | 服务端异常 | 全局异常提示 |

> 网关对未认证请求直接返回 HTTP 401 + `{code:401}`；Token 过期返回 `{code:4011}`。

### 双令牌体系（本阶段新增能力）

| 令牌类型 | 签发方 | 适用前端 | 网关注入的请求头 |
| --- | --- | --- | --- |
| 管理端 Token | `POST /api/admin/auth/login` | Web 管理后台 | `X-User-Id` / `X-Brand-Id` / `X-Store-Ids` / `X-Permissions` ... |
| 会员端 Token | `POST /api/auth/wx-login`、`POST /api/auth/member-login` | 微信小程序 | `X-Member-Id` / `X-Brand-Id` |

> 网关当前**只解析管理端 Token**。本阶段需扩展为「先试管理端、再试会员端」，
> 并把会员身份以 `X-Member-Id` 下发到下游服务。

## 三、会员端接口（微信小程序）——**整块新增**

前缀 `/api/{member,product,order,payment,wallet,auth}/`，默认需要**会员端 Token**。

> **匿名白名单**（已写入网关 `JwtAuthGlobalFilter`）：`/api/auth/wx-login`、`/api/auth/member-login`、
> `/api/auth/member-register`、`/api/auth/stores`、`/api/auth/stores/**`、`/api/product/**`。
> 门店与商品浏览免登录，下单/订单/钱包必须登录。
业务逻辑全部复用已迁移的 service，本层只做「会员身份 + 出入参适配」，不重写业务。

### 3.1 认证（auth-service）

| 方法 | 路径 | 请求 | 响应 | 白名单 |
| --- | --- | --- | --- | --- |
| POST | `/api/auth/wx-login` | `{ code, nickname?, avatarUrl?, phone? }` | `{ token, expiresIn, memberId, memberNo, isNew, nickname, avatarUrl, phone }` | 是 |
| POST | `/api/auth/member-login` | `{ phone, password }` | 同上（`isNew=false`） | 是 |
| POST | `/api/auth/member-register` | `{ phone, password, nickname? }` | 同上 | 是 |
| GET | `/api/auth/member/me` | — | `MemberVO` | 否 |
| GET | `/api/auth/stores` | — | `[{ id, storeName, address, phone, businessStatus, openTime, closeTime, latitude, longitude }]` | 是 |
| GET | `/api/auth/stores/{id}` | — | 单个门店 | 是 |

**微信登录在无商户资质下的实现**：`code2session` 走 **Mock 适配器**
（`teaclub.auth.wx.mock=true`）：`openid = "mock_" + sha256(code).substring(0,24)`，
不访问微信服务器。开关关闭时才真正调用 `https://api.weixin.qq.com/sns/jscode2session`，
需要 `app-id` / `app-secret` 配置。**这是与支付 Mock 一致的既定策略，不是未完成项。**
绑定关系存 `mem_member_wx`（openid ↔ memberId），首次登录自动建会员。

## 七、验收口径

1. Web：`npm run build` 通过，`npm run dev` 可启动，登录后 13 个页面均能取到**真实数据**。
2. 小程序：可导入微信开发者工具，`npm run build:mp-weixin` 产物可编译。
3. 所有请求 url 前缀为网关地址，**不存在硬编码服务端口**。
4. 充值/支付：小程序下单 → 模拟支付通知 → 钱包余额由后端入账 → 前端轮询到账。
5. 会员可查询自身流水与充值记录。
