## 5. 命名规范

### 5.1 后端

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 类 | UpperCamel | `WalletTransactionService` |
| 方法 | lowerCamel | `rechargeIn` |
| 常量 | UPPER_SNAKE | `MAX_LOGIN_FAIL` |
| Entity | 表名驼峰 | `WalWalletTransaction` |
| DTO | `XxxCmd` / `XxxQuery` / `XxxCreateReq` | `RechargeInCmd` |
| VO | `XxxVO` / `XxxDetailVO` | `WalletDetailVO` |
| Mapper | `XxxMapper` | `WalWalletMapper` |
| 接口/实现 | `XxxService` / `XxxServiceImpl` | — |

### 5.2 前端

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 组件文件 | PascalCase 或 kebab-case（目录内统一） | `DataTable.vue` |
| 组合式函数 | `useXxx` | `usePermission` |
| Store | `useXxxStore` | `useUserStore` |
| 类型 | PascalCase | `OrderDetailVO` |
| 常量 | UPPER_SNAKE | `ORDER_STATUS` |

### 5.3 单号规则

| 单号 | 格式 | 示例 |
| --- | --- | --- |
| 订单号 | `TC` + yyyyMMdd + HHmmss + 3位序列 | `TC20260101120300001` |
| 充值单号 | `RC` + 同上 | `RC20260101120300001` |
| 支付单号 | `PAY` + yyyyMMddHHmmss + 6位随机 | `PAY20260101120345123456` |
| 退款单号 | `RF` + 同上 | `RF20260101120345123456` |
| 钱包流水号 | `WT` + 同上 | `WT20260101120345123456` |

> 生成策略：时间前缀 + 原子序列（Redis `INCR` 或数据库序列），保证唯一且可排序；唯一索引兜底。

## 6. Git 与提交规范

### 6.1 分支

```
main        稳定可交付
develop     集成分支

```

type: feat | fix | docs | style | refactor | test | chore

## 7. 文件规模约束

| 约束 | 阈值 | 理由 |
| --- | --- | --- |
| 单个 Java 类 | ≤ 500 行 | 超限说明职责过多，需拆分 |
| 单个 Vue 页面 | ≤ 600 行 | 超出应抽取业务组件 |
| 单个方法 | ≤ 80 行 | 提升可读性与可测性 |
| 单个 Service 公共方法数 | ≤ 15 | 过多应拆分领域 |
