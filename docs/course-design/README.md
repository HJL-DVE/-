## 使用顺序建议

1. 答辩前：浏览器打开 答辩PPT.html，按 F 全屏演示；
2. 答辩演示项目：按 DEPLOYMENT.md 启动 Docker 或 IDEA/VSCode 直接跑；
3. 提交材料：打印 说明书 + 数据库设计文档 + 测试报告；
4. 截图：按 截图清单.md 逐页截取放入 screenshots/。
