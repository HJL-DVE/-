## 1. 充值方案 `/api/admin/wallet/plans`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/plans` | `wallet:plan:list` | 方案列表 |
| GET | `/plans/available?storeId=&memberId=` | 仅需登录 | 该门店下当前会员可用方案 |
| GET | `/plans/{id}` | `wallet:plan:list` | 方案详情 |
| POST | `/plans` | `wallet:plan:create` | 新增方案 |
| PUT | `/plans/{id}` | `wallet:plan:update` | 编辑方案 |
| DELETE | `/plans/{id}` | `wallet:plan:delete` | 删除方案 |

**新增方案请求示例**：

```json
{
  "planCode": "RC200",
  "planName": "充 200 送 30",
  "rechargeAmount": 20000,
  "giftAmount": 3000,
  "giftExpireDays": 365,
  "minLevelId": null,
  "customAmountEnabled": 0,
  "perMemberLimit": 0,
  "sort": 2,
  "status": "ENABLED",
  "startTime": "2026-01-01 00:00:00",
  "endTime": "2026-12-31 23:59:59",
  "storeIds": []
}
```

> `storeIds` 为空数组表示全部门店参与。`minLevelId` 为空表示不限等级。

## 2. 会员钱包 `/api/admin/wallet`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/wallet/accounts` | `wallet:account:list` | 钱包分页（受门店数据权限约束） |
| GET | `/wallet/accounts/member/{memberId}` | `wallet:account:list` | 按会员查钱包 |
| POST | `/wallet/accounts/member/{memberId}/open` | `wallet:account:list` | 开通钱包 |
| GET | `/wallet/transactions` | `wallet:txn:list` | 资金流水分页 |
| GET | `/wallet/transactions/member/{memberId}?limit=20` | `wallet:txn:list` | 会员近期流水 |
| GET | `/wallet/reconcile` | `payment:reconcile` | **资金对账** |

**钱包查询响应**：

```json
{
  "code": 0,
  "data": {
    "walletId": 1,
    "memberId": 3,
    "memberPhone": "138****0003",
    "principalBalance": 20000,
    "giftBalance": 3000,
    "totalBalance": 23000,
    "totalPrincipalIn": 20000,
    "totalGiftIn": 3000,
    "totalPrincipalOut": 0,
    "totalGiftOut": 0,
    "totalRefundIn": 0,
    "status": "NORMAL"
  }
}
```

> 所有金额单位为**分**（`Long`）。前端展示时除以 100。

**流水响应（含前后余额）**：

```json
{
  "txnNo": "WT20261119103200000001",
  "bizType": "CONSUME_OUT",
  "bizTypeName": "消费扣款",
  "bizNo": "TC20261119103200000002",
  "principalChange": -500,
  "principalBefore": 20000,
  "principalAfter": 19500,
  "giftChange": -3000,
  "giftBefore": 3000,
  "giftAfter": 0,
  "storeId": 1,
  "storeName": "TeaClub·西湖旗舰店"
}
```

**对账响应**：

```json
{
  "code": 0,
  "data": {
    "consistent": true,
    "inconsistentCount": 0,
    "details": []
  }
}
```

## 3. 充值订单 `/api/admin/wallet/recharges`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| POST | `/recharges` | `wallet:recharge:list` | 创建充值订单 |
| GET | `/recharges` | `wallet:recharge:list` | 充值记录分页 |
| GET | `/recharges/{rechargeNo}` | `wallet:recharge:list` | 充值详情 |
| POST | `/recharges/{rechargeNo}/cancel` | `wallet:recharge:list` | 取消未支付充值单 |

**创建充值请求**（注意：**不含金额字段**）：

```json
{
  "memberId": 3,
  "storeId": 1,
  "planId": 2,
  "payChannel": "MOCK"
}
```

**响应**（金额由服务端按方案计算）：

```json
{
  "code": 0,
  "data": {
    "rechargeNo": "RC20261119103200000001",
    "memberId": 3,
    "rechargeAmount": 20000,
    "giftAmount": 3000,
    "status": "PENDING",
    "planName": "充 200 送 30"
  }
}
```

## 4. 订单 `/api/admin/order`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| POST | `/order/quote` | `order:create` | 金额试算（不落单） |
| POST | `/order/orders` | `order:create` | 创建订单 |
| POST | `/order/orders/{orderNo}/pay-balance` | `order:pay:balance` | 余额支付 |
| GET | `/order/orders` | `order:list` | 订单分页 |
| GET | `/order/orders/{orderNo}` | `order:detail` | 订单详情 |
| POST | `/order/orders/{orderNo}/cancel` | `order:cancel` | 取消订单 |
| PATCH | `/order/orders/{orderNo}/status` | `order:detail` | 状态流转 |

**创建订单请求**（**只传 skuId + quantity，无价格字段**）：

```json
{
  "storeId": 1,
  "memberId": 3,
  "orderSource": "POS",
  "items": [
    { "skuId": 1, "quantity": 2 }
  ],
  "payWithBalance": false,
  "remark": "少冰"
}
```

**订单响应（金额全部服务端计算）**：

```json
{
  "orderNo": "TC20261119103200000002",
  "storeId": 1,
  "totalAmount": 3500,
  "levelDiscountAmount": 0,
  "couponAmount": 0,
  "discountAmount": 0,
  "payableAmount": 3500,
  "paidAmount": 3500,
  "balancePrincipalAmount": 500,
  "balanceGiftAmount": 3000,
  "status": "PAID",
  "statusLabel": "已支付",
  "payChannel": "BALANCE",
  "items": [
    { "skuId": 1, "skuName": "招牌珍珠奶茶/中杯", "unitPrice": 1750, "quantity": 2, "actualAmount": 3500 }
  ]
}
```

## 5. 支付 `/api/admin/payment`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| POST | `/payment/create` | `order:create` | 发起支付 |
| GET | `/payment/orders/{paymentNo}/query` | `payment:query` | 主动查单 |
| GET | `/payment/orders` | `payment:order:list` | 支付单分页 |
| POST | `/payment/refunds` | `order:refund` | 申请退款 |
| GET | `/payment/refunds` | `payment:refund:list` | 退款单分页 |
| GET | `/payment/notify-logs` | `payment:notify:list` | 通知记录 |

**发起支付**（金额由服务端按业务单确定）：

```json
{
  "bizNo": "RC20261119103200000001",
  "bizType": "RECHARGE",
  "channel": "WECHAT_JSAPI"
}
```

```json
{
  "code": 0,
  "data": {
    "paymentNo": "PAY20261119103200000003",
    "provider": "MOCK",
    "channel": "WECHAT_JSAPI",
    "amount": 20000,
    "status": "PAYING",
    "invokeParams": {
      "timeStamp": "1763000000",
      "nonceStr": "abc...",
      "package": "prepay_id=mock_prepay_...",
      "signType": "RSA",
      "paySign": "mock_sign_..."
    },
    "tip": "当前为 Mock 支付渠道，请调用 POST /api/payment/mock/notify 模拟支付成功"
  }
}
```

**申请退款**：

```json
{
  "orderNo": "TC20261119103200000002",
  "refundAmount": 3500,
  "reason": "顾客取消"
}
```

```json
{
  "code": 0,
  "data": {
    "refundNo": "RF20261119103200000004",
    "refundAmount": 3500,
    "refundPrincipalAmount": 500,
    "refundGiftAmount": 3000,
    "refundCashAmount": 0,
    "channel": "BALANCE",
    "status": "SUCCESS"
  }
}
```

> `refundPrincipalAmount` / `refundGiftAmount` 由系统按**原扣款构成**自动分摊，调用方只指定退款总额。

## 6. Mock 支付接口（仅开发环境）

> **仅在 `teaclub.payment.provider=mock` 时注册**。provider 为 `wechat-v3` 时这些路由**物理不存在（404）**。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/payment/mock/notify` | 模拟支付成功 |
| POST | `/api/payment/mock/fail` | 模拟支付失败 |
| POST | `/api/payment/mock/refund-notify` | 模拟退款成功 |

```json
// POST /api/payment/mock/notify
{ "paymentNo": "PAY20261119103200000003" }

// 故意传错误金额，用于验证金额校验会拒绝
{ "paymentNo": "PAY20261119103200000003", "amount": 1 }
```

## 7. 错误码（资金相关）

| 错误码 | 含义 |
| --- | --- |
| `10002` | 请求参数不合法（含余额不足、状态不允许） |
| `10101` | 未登录或登录失效 |
| `10201` | 没有操作权限 |
| `10202` | 没有该门店的数据权限 |
| `40001` | 会员不存在 |
| `50008` | 门店定价低于最低保护价 |
| `50009` | 价格必须大于 0 |
| `50000` | 系统内部错误 |

## 8. 调用顺序（完整充值 + 消费 + 退款）

```text
1. GET  /api/admin/wallet/plans/available?storeId=1&memberId=3     查看可用充值方案
2. POST /api/admin/wallet/recharges                               创建充值单
3. POST /api/admin/payment/create                                 创建支付单，取回支付参数
4. POST /api/payment/mock/notify                                  （Mock）模拟支付成功通知
5. GET  /api/admin/wallet/accounts/member/3                       确认余额到账
6. POST /api/admin/order/quote                                    订单试算
7. POST /api/admin/order/orders                                   创建订单
8. POST /api/admin/order/orders/{orderNo}/pay-balance             余额支付
9. POST /api/admin/payment/refunds                                申请退款
10. GET /api/admin/wallet/reconcile                               对账校验
```
