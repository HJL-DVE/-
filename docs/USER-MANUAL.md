## 一、系统概览

```text
会员端（微信小程序）        管理端（Vue Web 后台）
  浏览商品 / 下单             门店/商品/会员/订单管理
  钱包充值 / 余额支付         充值与钱包流水
  领券 / 积分 / 签到          营销（券/积分/活动/商城）
  查看活动与等级权益          经营报表（总部/门店）
                              系统管理（用户/角色/门店）
```

技术形态：9 个 Spring Cloud 微服务（Nacos 注册、Gateway 统一入口、
RabbitMQ 事件、MySQL 分库、Redis 缓存），Web 用 Vue3+ElementPlus+ECharts。

## 二、管理后台使用

| hqadmin | TeaClub@123 | 总部管理员 | 全部菜单，全部门店数据 |

登录后右上角显示当前角色；左侧菜单按角色过滤。

### 2.2 门店管理

「门店管理 → 门店列表」：新增门店（S001-004 已预置 4 家）、启停、编辑。

### 2.3 商品管理

- 商品信息：SPU 列表（含图片、价格）、上下架；
- 分类管理（占位页，本期未实现）；
- 商品图片存储在 `backend/teaclub-cloud/product-service/src/main/resources/static/images/`。

### 2.4 会员管理

- 会员列表：搜索、查看消费统计；
- 会员等级：4 级预置（普通/银卡/金卡/钻石），可增改删；
  选中等级后下半区可维护营销权益（生日券/积分倍率/专属券等）；
- 会员内容（占位页本期未实现）。

### 2.5 钱包管理

- 充值套餐：配置「充 X 送 Y」（如充100送10）；
- 充值订单：全平台充值流水；
- 钱包账户：每位会员余额（本金/赠送分列）；
- 钱包流水：RECHARGE_IN / CONSUME_OUT / REFUND 等全类型。

### 2.6 营销管理

- 优惠券：模板 CRUD（满减/折扣/兑换/新人/生日等类型）、启用停用、发放；
- 会员等级：见 2.4；
- 营销活动：8 类活动（新人礼包/生日/节日/连续签到/满赠/积分商城/门店/召回），
  奖励配置 JSON（满额门槛、券模板、积分）；
- 积分商城：兑换商品（券类/实物/积分包），定价与库存。

### 2.7 经营报表查看

「经营报表」菜单（总部/店长可见，收银员无）：

| 页面 | 内容 |
| --- | --- |
| 经营驾驶舱 | 今日销售/订单/充值(本金+赠送)/退款/会员/门店 6 卡 + 7日/30日趋势 + 门店排行 + 热销 + 会员增长 |
| 门店驾驶舱 | 单店 6 卡 + 每日趋势 + 每小时订单 + 热销 + 支付占比 |
| 销售分析 | 趋势 + 商品销量/金额排行切换 + 门店对比 |
| 商品销售分析 | 商品趋势 + 双排行 + 分类排行 |
| 会员分析 | 增长 + 等级分布饼 + 消费排行 |
| 充值/支付/退款统计 | 五口径分卡（**支付金额均为模拟数据**） |
| 营销分析 | 券领用/积分/等级分布 |

顶部支持门店筛选 + 天数切换；金额单位统一元（后端存分）。

### 2.8 订单管理

订单列表（筛选门店/状态/会员）→ 详情含商品明细、支付方式、券抵扣；
操作：退款（走 payment 退款链路）。

### 2.9 支付管理

支付订单（channel=WECHAT_*/MOCK，状态机）、退款单、通知日志。
**支付为 Mock 模拟**，界面标注 provider=MOCK。

### 2.10 系统管理

用户、角色（含权限分配）、门店授权（店长绑定门店）。个别占位页本期未实现。

## 三、小程序使用（会员端）

### 3.1 登录

启动即 wx-login（mock）。同一 code 字符串固定对应同一会员。

### 3.2 核心操作路径

```text
首页 → 门店/商品 → 加购 → 下单（可选优惠券）
  → 支付方式：钱包余额 / 微信支付（Mock 自动成功）
会员中心 → 钱包 → 充值（选套餐）→ 模拟支付 → 到账（本金+赠送）
会员中心 → 积分 → 签到 / 积分商城兑换
优惠券中心 → 领券 → 我的优惠券 → 下单时选用
```

### 3.3 会员等级

累计消费达到门槛自动升级（等级折扣与积分倍率生效）。

## 四、常见问题

| 问题 | 说明 |
| --- | --- | ---
| 充值后余额没变？ | Mock 支付回调需 1-3 秒异步入账；检查钱包流水 |
| 领券提示"操作过于频繁"？ | 800ms 内重复点击的风控锁，稍后重试 |
| 报表数字不对？ | 报表口径：销售=订单实付；充值=本金（赠送另列）；模拟支付≠真实收款 |
| 店长看不到报表？ | 收银员角色无 report:view 权限（设计如此） |
| 支付失败？ | Mock 模式默认成功；失败场景用 `/api/payment/mock/fail` 模拟 |
