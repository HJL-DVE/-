## 一、交付内容

### 1.1 report-service（端口 9008，独立库 report_db）

```text
report-service
  ReportApplication        @MapperScan + @EnableScheduling（无 AMQP：不发事件，不引 common-messaging）
  security/ReportScope     数据权限（与各服务 StoreScope 同语义）
  mapper/ReportMapper      跨库只读聚合 SQL（15 个查询）
  service/ReportService    口径转换 + 补零趋势 + 占比计算
  controller/ReportController  11 个 GET 接口，全部 @PreAuthorize("report:view")
```

**跨库只读策略（课程设计简化，如实说明）**：
需求书要求「优先 OpenFeign 调已有统计接口」。现有 7 个稳定服务只有零散 summary 接口
（无趋势/排行/占比聚合），为不改动它们，report-service 的 `tc_report` 账号
授予全部业务库 **SELECT-only** 权限（与阶段三 `tc_migrator` 同模式），
Mapper 只写 SELECT；`ReportFeignClient` 已就位但当前未启用，后续补服务端聚合接口时可平移。
**没有任何跨库写操作。**

### 1.2 数据库账号（init SQL 已固化为 mysql/init/03-report-db.sql，幂等）

```sql
CREATE DATABASE report_db;  CREATE USER tc_report;  GRANT ALL ON report_db.*;
GRANT SELECT ON order_db / wallet_db / member_db / marketing_db / payment_db / iam_db;
```

### 1.3 接口清单（全部支持日期筛选 days 与门店筛选 storeId，权限后端强制）

| --- | --- |
| GET /api/report/dashboard/overview | 总部驾驶舱：门店数/会员数/今日销售/订单/充值(本金+赠送)/退款/新增会员/门店排行 |
| GET /api/report/dashboard/trend | 趋势（7/30/90 天，缺失日补零） |

| GET /api/report/store/overview | 门店驾驶舱（含客单价、热销商品） |
| GET /api/report/store/compare | 门店销售对比 |
| GET /api/report/product/ranking | 商品排行（metric=qty|amount，白名单防注入） |
| GET /api/report/member/overview | 会员总数/等级分布/消费排行 |
| GET /api/report/member/growth | 新增会员趋势 |
| GET /api/report/recharge/overview | 充值：笔数/本金/赠送/到账（giftNotCountedAsPayment=true） |
| GET /api/report/payment/overview | 支付：渠道占比 + mockPaymentMark + 钱包消费单列 |
| GET /api/report/refund/overview | 退款统计与趋势 |
| GET /api/report/marketing/overview | 券领取/使用/使用率、积分发放/兑换、等级分布 |

### 1.4 金额口径（严格按需求书）

| 指标 | 来源 | 说明 |
| --- | --- | --- |
| 充值金额 | wal_recharge_order.recharge_amount | 充 100 送 20 → 充值 100 |
| 赠送金额 | gift_amount | 单列展示，**不算收款**（接口返回 giftNotCountedAsPayment=true） |
| 钱包到账 | 本金+赠送 | 120 |
| 模拟支付金额 | pay_payment_order.amount（SUCCESS） | **明确标注模拟数据**（返回体带 mockPaymentMark） |
| 钱包消费 | oms_order.balance_principal+gift | 单列，**不重复计入支付收款** |
| 销售金额 | oms_order.payable_amount | 与订单统计口径一致（PAID/COMPLETED/REFUNDING/REFUNDED） |
| 退款金额 | pay_refund_order.refund_amount（SUCCESS） | |
